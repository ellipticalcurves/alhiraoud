
# Al Hira Oud

Luxury fragrance and lifestyle storefront.

🌐 **Live Website:** [Visit Al Hira Oud](https://ellipticalcurves.github.io/alhiraoud/)

## About

Al Hira Oud is a website project featuring an immersive 3D storefront experience, built with React, TypeScript, Vite and PlayCanvas.

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- PlayCanvas Gaussian Splatting

## Run Locally

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deployment

The website is hosted on GitHub Pages and automatically deployed through GitHub Actions whenever changes are pushed to the `main` branch.

**Repository:** [ellipticalcurves/alhiraoud](https://github.com/ellipticalcurves/alhiraoud)
